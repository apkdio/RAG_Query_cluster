标注规则

标签（每个簇必选）：正确 = 原始 core 未变；部分 = core 被移走过成员；不正确 = 整簇错误；新建 = 人工建的簇。

不作处理：独立开关，只表示这批暂不治理，不替代质量标签。

core 只出不进：新增 query 只能拖到目标簇的 suspect IN；最终聚类结果 = core + IN。

suspect OUT：必须清零，接受就拖进 core/IN，不接受就拖到别的簇 IN 或垃圾桶。

删除簇：等于判定整簇错误，原始 core 会记入导出（label=1, deleted=true）。

灰色划线块：原成员被移出后留在原簇的占位，移回或 Ctrl+Z 后消失，不参与统计。

编号：C1:Q1 = 原簇 1 的第 1 条；拖动不变，便于追踪来源。

快捷键：Ctrl+Z 撤销，Ctrl+Shift+Z 重做；Ctrl+拖动空白平移；Ctrl+滚轮缩放；双击 query 复制文本。

导出：CSV/JSON 含 label、core、suspect_in、final_members、slug_keywords、no_action 等字段。
